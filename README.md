# R-140-radio-mast-manuals

Here are the original Russian and English translation of the manual for R-140 type telescopic winch operated radio antenna masts, 
named 'Technical description and Operating instructions' or 'Техническое описание и инструкция по эксплуатации'.

The manual refers to the ХЖ4.115.120 TO type masts, which are more commonly named as R-140 masts.

If you find yourself such a mast, make sure to properly grease all pulleys and clean aluminum sub-masts with diesel and then apply thin weatherproof grease,
such as lithium based or similar. The winch internals must also be lubed to avoid rusting of the first cable section. If yours has been outside for
a long time, I recommend disassembling all mast sections and greasing the bottom cable-mast joint as it seems to get very rusty over time (See pic.). 

And a warning before use, the mast MUST NOT be deployed without at least 10kg on the top, or it will not retract no matter how well it is greased!
